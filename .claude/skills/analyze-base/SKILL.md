# ベース作品分析スキル

ヒット作の「売れる構造」を抽出し、`novels/<作品ID>/knowledge_base/` に執筆時参照用の分析ファイルを作る。

## 受け付ける入力

- ベース作品の本文（ユーザーが貼り付けたもの。数話分あると精度が上がる）
- ベース作品の特徴のユーザーによる説明
- 「この作品の episodes/ を分析して」（自作の既存話から文体を抽出するケース）

※ なろうのURLだけ渡された場合: 本文の自動取得は行わない（規約・ネットワーク制約のため）。「分析したい話の本文を貼り付けてほしい」と依頼する。作品名から一般知識で書ける範囲（ジャンル定番パターン）は先に埋めておく。

## 生成するファイル

既存の `novels/gaiko-maou/knowledge_base/` の2ファイル構成を踏襲する:

### 1. `novel_analysis.md` — その作品固有の文体・構造分析

分析する観点:
- 視点・ナレーション（人称、視点切替の有無とその効果、心の声の表記法）
- 主人公の「格」の見せ方（どういう行動・描写で読者に有能さを伝えているか)
- 山場シーンの構造（交渉・戦闘・ざまぁ等、その作品の見せ場の型を手順化する）
- 脇役の機能（リアクション役・解説役・ヘイト役などの役割分担）
- 話末の引きのパターン（実例を抜き出す）
- 固有名詞・世界観用語の一覧表

### 2. `narou_patterns.md` — ジャンル汎用の執筆パターン

- 1話の文字数・起承転結の型
- そのジャンルの感情曲線（読者が何にカタルシスを感じるか）
- 会話・地の文のバランスと書き方
- 頻出要素（俺TUEE・ざまぁ・成り上がり等）のその作品流の適用方法
- 話タイトルの付け方

## 分析の方針

- **再現可能な形で書く**: 「面白い」ではなく「なぜ面白いか→どう書けば再現できるか」を手順・型として言語化する
- **実例を引用する**: 本文が提供されている場合、型の説明には短い実例を添える
- **既存ファイルがある場合は上書きでなくマージ**: 新しい知見を該当セクションに追記する

## 完了後

生成・更新したファイルと、抽出した主要パターンを3〜5点で報告する。

# 新作品登録スキル

`novels/<作品ID>/` に新しい作品の設定一式を作る。

## 受け付ける入力（どれか一部だけでもよい）

- ベースにしたいヒット作の名前・URL・「こういう系」という説明
- タイトル（仮でもよい。なければ提案する）
- ジャンル・コンセプト（例「追放ざまぁ×料理チート」）
- 主人公・主要キャラの設定（断片的でよい）
- 世界観のイメージ
- プロット（一行あらすじ〜詳細まで何でも）
- 1話の文字数目安・視点・文体の希望

## 手順

### 1. 情報の聞き取り

ユーザーの最初の入力で足りない場合、AskUserQuestion で**最小限**だけ確認する。確認するのは以下の優先順:

1. ジャンル・コンセプト（これがないと何も決められない）
2. 主人公の核となる特徴（チート能力・職業・転生/追放などの導入）
3. ベース作品の有無

それ以外（キャラ名・地名・細部）は聞かずにAIが提案で埋める。**全項目が揃うまで質問を繰り返さない**こと。2回質問しても埋まらない項目は「未定」または提案値で進める。

### 2. 作品IDの決定

短い英数字ケバブケース（例: `gaiko-maou`）。タイトルから自動生成し、既存IDと衝突しないようにする。

### 3. ファイル生成

`templates/` の各テンプレートをベースに以下を生成する。テンプレートの構成・見出しは保ちつつ、**内容はその作品に合わせて具体的に書く**（プレースホルダのまま残さない。本当に決まっていない項目のみ「未定」と書く）:

```
novels/<作品ID>/
  novel.json
  settings/world.md
  settings/characters.md
  settings/plot_overview.md
  settings/continuity.md        # 初期状態は「まだ確定事実なし」
  knowledge_base/               # 空で作成（analyze-base で埋める）
  episodes/                     # 空で作成
```

- AIが補完・提案した設定には、ユーザー提供の設定と区別できるよう見出し近くに `<!-- AI提案 -->` コメントを付ける
- plot_overview.md の「禁止事項」は、そのジャンルの定番の地雷（例: 追放ざまぁなら「主人公が追放元を安易に許す」）をAIが考えて必ず3〜5項目入れる

### 4. knowledge_base の初期化

- ベース作品が指定され、本文や特徴の情報が得られる場合: `/analyze-base` 相当の分析を行い `knowledge_base/` に分析ファイルを作る
- 情報がない場合: そのジャンルの一般的ななろうパターンをまとめた `knowledge_base/narou_patterns.md` を生成する（既存作品 `novels/gaiko-maou/knowledge_base/narou_patterns.md` の構成を参考に、ジャンル特化の内容で書く）

### 5. 報告

生成したファイル一覧と、AIが提案で埋めた主要な設定を箇条書きで報告し、「設定はいつでも直接編集 or 依頼で修正できる」「執筆は /write-episode で開始できる」ことを伝える。

# エピソード執筆スキル

CLAUDE.md の「執筆パイプライン」を実行する。以下は手順の詳細。

## 引数の解釈（すべて省略可）

- **作品ID**: `novels/` 配下のフォルダ名。省略時、作品が1つならそれを使う。複数あれば AskUserQuestion で確認する。
- **話数**: 省略時は `episodes/` の最終話の次の番号。
- **プロット**: 一行・箇条書き・長文いずれも可。省略時は `plot_overview.md` の「今後の展開」から次の話のプロットを自分で立案し、立案内容を明記した上でそのまま執筆を続行する（許可待ちで止まらない）。
- **複数話指定**（例「13〜15話」）: 1話ずつ順番にパイプラインを完走させる。前の話の保存と continuity 更新が終わってから次の話に着手する。

## 手順

### 1. コンテキスト読み込み

対象作品の以下を読む:
- `novel.json`（文字数目標・視点・参照話数）
- `settings/` 全ファイル（world / characters / plot_overview / continuity）
- `knowledge_base/` 全ファイル（文体分析・執筆パターン）
- 直近エピソード `recent_chapters_for_context` 話分（文体の連続性と文脈維持のため必ず全文読む）

### 2. 構成設計

執筆前に、その話の設計を頭の中で固める:
- 起承転結の各パート（knowledge_base のパターンに従う）
- 視点（novel.json / plot_overview の視点ルールに従う。視点切替がある作品は配置も決める）
- 登場キャラと各自の口調確認
- 張る伏線・回収する伏線（continuity.md と照合）
- 話末の引きの内容

### 3. 執筆

- 目標文字数 `episode_length_target` ±20%
- 冒頭1〜3行で状況提示。説明から始めない
- 会話比率は作品設定に従う（デフォルト40〜60%）
- 各キャラの口調を characters.md どおりに維持
- セクション区切りは既存話の体裁（`---` 等）に合わせる

### 4. 自己チェック（保存前に必ず実施）

```
wc -m で文字数を実測する（目分量で済ませない）
```

- [ ] 文字数 ±20%以内
- [ ] 口調の一貫性（特に複数キャラの会話シーン）
- [ ] plot_overview.md「禁止事項」非抵触
- [ ] continuity.md・過去話との無矛盾（固有名詞・能力・時系列・各人の知識状態）
- [ ] 話末の引き
- [ ] タイトルがなろう読者向け（knowledge_base のタイトルパターン参照）

不合格項目は修正してから保存する。

### 5. 保存

`novels/<作品ID>/episodes/` に既存話の命名規則で保存する（例: `ep13_１３．タイトル.md`）。ファイル先頭に話タイトルを `#` 見出しで入れる（既存話の体裁に合わせる）。

### 6. 設定への反映

- `settings/continuity.md` に追記: その話で確定した事実、張った伏線、回収した伏線、キャラの状態変化（負傷・移動・関係変化）
- 新キャラ・新固有名詞・新能力が出た場合: characters.md / world.md に追記
- プロットが plot_overview.md の予定から逸れた場合: plot_overview.md を現状に合わせて更新

### 7. 報告

保存先パス・実測文字数・チェック結果・次話への引きを簡潔に報告する。執筆中に独自に決めた設定があればそれも明記する。

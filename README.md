# AInovel — なろう系小説 AI自動執筆システム

なろう小説のヒット作をベースに、プロットや登場人物を登録して物語を出力するための Claude Code ネイティブの執筆システムです。Pythonスクリプトや外部APIキーは不要で、すべて Claude Code との対話で完結します。

## できること

1. **新作品の登録** — ベース作品・コンセプト・キャラなどの情報を断片的にでも渡せば、設定一式が生成される（足りない部分はAIが提案で補完）
2. **ベース作品の分析** — ヒット作の本文を貼り付けると、文体・構成・売れるパターンを知識ベース化
3. **エピソードの自動執筆** — 設定・知識ベース・過去話を読み込み、執筆 → 文字数/口調/禁止事項/整合性の自己チェック → 保存 → 伏線台帳の更新まで一気通貫

## 使い方

Claude Code でこのリポジトリを開き、以下のスラッシュコマンドを使います。

### 新作品を登録する

```
/new-novel 追放ざまぁ×料理チートで一作。主人公は宮廷料理人をクビになった青年
```

情報は一部だけでもOK。ジャンルすら未定なら `/new-novel` だけで起動し、対話で決められます。

### ベース作品を分析する

```
/analyze-base gaiko-maou に以下の本文を分析して反映して
（本文を貼り付け）
```

### エピソードを書く

```
/write-episode gaiko-maou 13話 プロット：ガルドが詫びに来るがヴォルドは処罰しない
```

- プロットは一行でも箇条書きでも長文でもOK。省略すれば plot_overview.md からAIが立案
- 「13〜15話」のような連続執筆も可能
- スラッシュコマンドなしで「第13話を書いて」と頼んでも同じパイプラインが走ります（CLAUDE.md 参照）

## ディレクトリ構成

```
novels/<作品ID>/          # 作品ごとに独立
  novel.json              # 基本情報（タイトル・主人公・文字数目安・視点）
  settings/
    world.md              # 世界観・勢力・地理・魔法体系
    characters.md         # キャラクター設定・口調・関係性
    plot_overview.md      # あらすじ・今後の展開・禁止事項・文体メモ
    continuity.md         # 整合性メモ（確定事実・伏線台帳）※執筆のたびに自動更新
  knowledge_base/         # ベース作品の文体分析・執筆パターン
  episodes/               # 完成原稿（epNN_タイトル.md）
templates/                # 新作品登録用テンプレート（埋められる所だけ書けばOK）
.claude/skills/           # スラッシュコマンドの定義
CLAUDE.md                 # 執筆パイプラインの定義（システムの中核）
```

## 登録済み作品

| 作品ID | タイトル |
|--------|---------|
| `gaiko-maou` | 外交官の俺、戦えない魔王に転生したが交渉だけで世界を支配する |

## 設定の編集

`novels/<作品ID>/settings/` のMarkdownを直接編集するか、Claude Code に「リリアの口調をもっと砕けた感じにして」のように頼めば反映されます。執筆中にAIが決めた設定も自動で settings に追記されるため、設定ファイルが常に最新の正となります。
